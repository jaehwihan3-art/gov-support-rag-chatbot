# 정제 규칙서

공고 원문 파일을 검색·판정에 쓰는 텍스트로 바꿀 때 적용하는 규칙이다.
텍스트 추출은 `baseline.py`의 `file_text()`(2단계 `build_corpus.py`도 같은 함수 사용), 추가 정제와 청킹은 `build_chunks.py`의 `clean_v2()`에서 한다.
규칙별로 실제 삭제·수정된 줄 수는 `data/chunks/chunk_stats.md`에 문서 유형별로 집계된다.

## 1. 문서 유형과 추출 방법

| 문서 유형 | 추출 방법 | 특징·주의점 |
|---|---|---|
| PDF | pypdf로 쪽마다 추출, 쪽 앞에 `[p.N]` 표시 | 쪽 번호를 메타데이터로 쓸 수 있음. 양쪽 맞춤 문단은 글자마다 띄어쓰기가 들어가는 경우가 있음. 스캔본은 글자가 거의 안 나옴 |
| HWP (구형 한글) | OLE 파일의 BodyText 섹션을 풀어 문단 텍스트(태그 67)만 읽음, 제어 문자(표·그림 자리) 건너뜀 | 쪽 정보 없음. 표 셀이 한 줄씩 끊겨 나옴 |
| HWPX | zip 안의 `Contents/section*.xml`에서 태그 제거 | 쪽 정보 없음. 문단 경계는 `</hp:p>` |
| DOCX | zip 안의 `word/document.xml`에서 태그 제거 | 거의 없음 |
| K-Startup 상세페이지 | 웹페이지에서 가장 긴 본문 영역의 글자 (`collect_kstartup_files.py`) | 공유·인쇄 같은 메뉴 문구가 섞임. 요약이라 짧아서 공고문 첨부와 함께 씀 |

## 2. 문서 거르기 (2단계, `build_corpus.py`)

| 규칙 | 기준 | 처리 |
|---|---|---|
| 읽을 수 없는 형식 | png·jpg·xlsx 등 | 제외 (포스터 이미지만 있는 공고는 OCR을 안 하므로 제외) |
| 스캔본 의심 | PDF 쪽당 100자 미만 | 제외 |
| 너무 짧음 | 공백 뺀 300자 미만 | 제외 |
| 깨진 문서 의심 | 글자 중 한글 비율 30% 미만 | 제외 |
| 서식·신청 양식 | 첨부 중 파일명에 서식·신청서·양식·서약서·확인서·계획서 등 | 제외 (본문으로 안 씀) |
| 중복 공고 | 본문 앞 5,000자(공백 제외)가 같음 | 먼저 나온 공고만 사용 |
| 범위 밖 | K-Startup 분류 '행사ㆍ네트워크' (평가셋 공고는 예외) | 제외 |
| 범위 밖 (2차) | 공고명에 '운영기관·수행기관·주관기관·운영사·협약기관·위탁기관' 바로 뒤에 '모집·선정·공모' (기업이 아니라 사업 수행 기관을 뽑는 공고. 평가셋 공고는 예외) | 제외 |
| 본문 선택 | `본문_` 파일 우선. 없거나 못 쓰면 이름에 '공고'가 있는 가장 긴 첨부. K-Startup은 상세페이지 글 + 공고문 첨부 | - |

## 3. 텍스트 정제 (3단계, `build_chunks.py`)

| 번호 | 규칙 | 적용 대상 | 판단 기준 | 예 |
|---|---|---|---|---|
| R1 | 페이지 번호 삭제 | 전체 | 줄 전체가 `- 3 -`, `3 / 12`, `page 3`. 숫자만 있는 줄(`3`)은 표 칸일 수 있어서 PDF 쪽의 첫 줄·마지막 줄일 때만 삭제 | `- 2 -` 삭제 |
| R2 | 반복 머리말·꼬리말 삭제 | PDF (3쪽 이상) | 같은 줄(2~120자, 2차에서 60→120)이 3쪽 이상, 전체 쪽의 40% 이상에 나옴 | 기관 로고 문구, 공고 번호 머리말, 쪽마다 반복되는 표 머리글 |
| R3 | 웹 메뉴 문구 삭제 | 상세페이지만 (PDF·HWP의 '목록' 같은 표 칸은 보호) | 줄 전체가 공유하기·URL복사·인쇄·페이스북·트위터·카카오톡·RSS 피드·스크랩·닫기·목록·바로보기·다운로드 등 | `URL복사` 삭제 |
| R4 | 글자 사이 띄어쓰기 복구 | 전체 (주로 PDF 양쪽 맞춤) | 한 글자씩 띄어 쓴 한글이 4글자 이상 이어짐 | `필 수 요 건` → `필수요건` |
| R5 | 특수·제어 문자 삭제 | 전체 (주로 HWP) | 사용자 정의 영역(U+E000~F8FF) 기호, 제어 문자 | HWP 글머리 기호 깨짐 |
| R6 | 공백·빈 줄 정리 | 전체 | 연속 공백 1칸, 빈 줄 3줄 이상 → 1줄 | - |
| R7 | 동의서·서약서 서식 삭제 (2차) | 전체 | '동의함·동의하지 않음', '수집·이용 목적', '보유 및 이용기간', '귀하', '(인)', '(서명)', '0000년 00월', '년 월 일', 빈 '기업명:' 칸, '서약합니다' 같은 표시가 8줄 간격 안에 3개 이상 몰린 구간 (앞 3줄, 뒤 1줄 포함). 한 줄만 있으면 안 지움 → 제출서류 목록의 '동의서 1부'는 남음 | 개인정보 수집·이용 동의서, 참가 서약서 |
| R8 | 부당개입(브로커) 주의 안내 삭제 (2차) | 전체 | '부당개입·브로커·신청 대행·성공보수·수수료를 요구' 같은 줄이 8줄 간격 안에 2개 이상 몰린 구간. 한 줄만 있으면 안 지움 → 신청 제외 사유로 한 줄 적힌 경우는 남음 | 정책자금 브로커 유형 ①~⑥ 안내문 |
| R9 | 상세페이지 하단 안내 삭제 (2차) | 전체 (상세페이지 글이 PDF와 합쳐진 공고도 있어서) | '본 저작물은 … 공공데이터포털', 'K-Startup에 공고되는 정보는 …', 줄 전체가 '이점 유의하여 주시기 바랍니다.', '접수 바로가기' | 사이트 공통 안내문 |
| R10 | HWP 개체 번호 삭제 (2차) | 전체 | 하이픈·쉼표 없이 10자리 넘게 이어진 숫자. 0으로 시작하면 전화번호라 보호, 뒤에 '원'이 오면 금액이라 보호 | `737222334229유의 사항` → `유의 사항` |

### 규칙을 고친 이력
- 1차 실행(2026-11-18): R1이 숫자만 있는 줄을 모두 지워서 HWP에서 1,289줄이 삭제됨 → 대부분 표 칸(금액·인원·번호)이라 판단. 숫자만 있는 줄은 PDF 쪽 가장자리일 때만 지우게 수정.
- 같은 실행: R3이 PDF에서도 224줄 삭제 (표 안 '목록', '인쇄' 같은 칸) → 상세페이지에만 적용하게 수정.
- 같은 실행: 지난 2단계 실행에서 남은 코퍼스 파일 17개(행사 공지)가 섞여 들어감 → `build_corpus.py`가 실행할 때 코퍼스를 새로 만들고, `build_chunks.py`는 목록표에서 '사용'인 공고만 읽게 수정.

- 2차 (2026-11-18, 청크 수동 검사 30개 결과 반영): 버림 판정 청크 대부분이 동의서·서약서, 브로커 안내, 사이트 하단 안내였음 → R7~R10 추가, R2 길이 한도 60→120자, R3에 바로보기·다운로드 추가, 운영기관 모집 공고 범위 밖 처리.
- 2차 시험 중: R10이 하이픈 없는 전화번호(`07045092582` 등) 17줄을 지움 → 0으로 시작하는 숫자는 보호하게 수정 (문의처 질문에 필요).
- 2차 시험 중: 운영기관 규칙을 '기관명 뒤 15자 안에 모집'으로 했더니 '디지털커머스 전문기관(소담스퀘어강원) 소상공인 모집'(소상공인 대상)까지 걸림 → 기관 단어 바로 뒤에 모집이 올 때만, '전문기관'은 뺌.
- 2차 시험 중: A1 마지막 조각이 5~99자로 남음 (이미 앞 청크의 겹침 100자 안에 들어 있는 중복) → 끝까지 담은 청크가 나오면 멈추게 수정. A1 100자 미만 청크 25개 → 0개.
- 2차: A2에서 `2. 동일한 자금의 … 경우`처럼 번호 붙은 목록 문장이 큰 제목으로 잡혀 section이 문장 조각이 됨 → 번호로 시작하는 줄은 40자 미만이고 '경우·다·함·음' 등으로 끝나지 않을 때만 큰 제목. `(1) 제목` 형태는 큰 제목에 추가.

### 2차 반영 전후 비교

| 항목 | 1차 | 2차 |
|---|---|---|
| 사용 공고 | 172 | 169 (운영기관 모집 3개 제외) |
| A1 청크 수 / 100자 미만 | 1,930 / 25 | 1,777 / 0 |
| A2 청크 수 / 섹션 있음 | 1,586 / 1,318 | 1,487 / 1,228 |
| R7~R10 삭제 줄 | - | 510 / 109 / 376 / 5 |

### 알려진 한계
- R4는 원래 단어 사이 띄어쓰기까지 없애서 `필요시신청기업에…`처럼 붙는다. 글자마다 띄어 쓴 원문은 단어 경계를 알 수 없어서 붙이는 쪽을 택했다 (검색 임베딩에는 글자 간격이 더 해로움).
- 표는 셀이 한 줄씩 끊겨 나온다. 표 구조 복원은 하지 않는다. A2 청킹에서 항목 경계로 나누면 같은 표가 한 청크에 남는 경우가 많다.
- 이미지로만 된 공고(포스터)와 스캔본은 OCR을 하지 않고 제외한다.

## 4. 청킹 전략

| 전략 | 방법 | 크기 |
|---|---|---|
| A1 고정 길이 | 글자 수로 자름 | 800자, 겹침 100자 (끝까지 담으면 멈춤) |
| A2 조항 단위 | 큰 제목(□, `1.`, `(1)`, `제N조`, Ⅰ., 붙임. 번호 줄은 40자 미만이고 문장으로 끝나지 않을 때만)과 항목(○, ㅇ, ➊, ①, `가.`, `1)`) 줄을 경계로 나눈 뒤 1,000자 안으로 이어 붙임. 한 항목이 1,000자를 넘으면 그 안에서만 800자로 나눔. 100자 미만 조각은 다음 조각에 붙임 | 최대 1,000자 |
